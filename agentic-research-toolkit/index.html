1 · Set up (once)

About 20 minutes. You need the course folder, the Python environment, and Claude or ChatGPT.

Download the course folder TTK29-2026 (from the course page). Install Miniforge (or Anaconda) if you don't have conda. Then open a terminal in TTK29-2026 and run:

Set up your AI app

  1. You need a paid Claude plan (Pro or higher).
  2. Download the Claude desktop app (macOS or Windows), install it and sign in.
  3. Windows only: install Git for Windows, then quit and reopen Claude.
  4. Click the Code tab. Under the message box, pick Local in the environment selector, then click the folder button → Open folder… and choose TTK29-2026/agentic-research-toolkit.
  5. Set the permission mode to Accept edits. Claude can then write files, and still asks before running commands.
  1. You need a ChatGPT plan that includes Codex (Plus or higher).
  2. Download the ChatGPT desktop app (macOS or Windows), install it and sign in.

Rules of the game

The agent must

  • Build solutions on course material and name the notebook and slide pages.
  • Cite only papers it actually found, with a working link.
  • Take every number from code that actually ran (runs/).
  • Report failures and negative results honestly.
  • Say so when it cannot search or run code — never fake it.

You should

  • Read each stage file before moving on — at least the summary.
  • Open two or three of the papers yourself.
  • Read the code in code/ and compare it to the course notebook.
  • Check one number in the report against runs/.
  • Answer the checkpoints yourself. "Method X did not help" is a fine result.
The agent writes polished text no matter what. Your grade depends on whether you understand and can defend the work — not on how nice the report looks.
